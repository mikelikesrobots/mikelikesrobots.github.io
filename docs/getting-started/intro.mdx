# Getting Started with Cloud Robotics

Build a robot you can control, connect it to the cloud, and learn how to keep it running. These tutorials combine written guides, videos, and example code.

## Choose your starting point

The physical-robot path below is sequential: each practical stage builds on the previous one. If you already have equivalent hardware or a working ROS 2 robot, you can start later in the path after checking the listed prerequisites.

<ol className="learning-path">
  <li>
    <span className="learning-path__number">Step 1</span>
    <h3>Understand the ROS 2 fundamentals</h3>
    <p>Begin with [Getting Started with ROS 2](/blog/getting-started-ros-2) before attempting the robot software.</p>
    <p className="learning-path__detail"><strong>Before:</strong> Basic programming and terminal familiarity.</p>
    <p className="learning-path__detail"><strong>Outcome:</strong> Understand nodes, messaging, packages, and the main command-line tools.</p>
  </li>
  <li>
    <span className="learning-path__number">Step 2</span>
    <h3>Build and test the CamJam robot</h3>
    <p>Follow [Your First Robot Kit: CamJam EduKit #3](/blog/camjam-edukit) and its video series in order.</p>
    <p className="learning-path__detail"><strong>Before:</strong> The kit, a Raspberry Pi, power supplies, a microSD card, and another computer.</p>
    <p className="learning-path__detail"><strong>Outcome:</strong> A complete Ubuntu-based robot with tested motors and sensors.</p>
  </li>
  <li>
    <span className="learning-path__number">Step 3</span>
    <h3>Install ROS 2 on the robot</h3>
    <p>[ROS 2 on a Raspberry Pi Robot](/blog/raspi-camjam-ros2) starts with the CamJam robot already assembled, running Ubuntu, and tested. Complete step 2 first unless you have prepared equivalent hardware yourself.</p>
    <p className="learning-path__detail"><strong>Before:</strong> Steps 1 and 2, with the completed robot accessible over SSH.</p>
    <p className="learning-path__detail"><strong>Outcome:</strong> ROS 2 nodes combining line following and obstacle avoidance.</p>
  </li>
  <li>
    <span className="learning-path__number">Step 4</span>
    <h3>Make the first cloud connection</h3>
    <p>Complete [AWS account and budget setup](#getting-started-with-aws), learn [AWS IoT Core](#aws-iot-core), then follow [Send ROS 2 data to AWS IoT Core](#connecting-to-the-cloud).</p>
    <p className="learning-path__detail"><strong>Before:</strong> ROS 2, an AWS account with a budget alert, and the AWS CLI.</p>
    <p className="learning-path__detail"><strong>Outcome:</strong> An IoT Thing securely sending ROS 2 data with an X.509 certificate.</p>
    <p className="learning-path__note">The sample uses Ubuntu 22.04 and ROS 2 Humble, so it can run on a separate development machine.</p>
  </li>
  <li>
    <span className="learning-path__number">Step 5</span>
    <h3>Build a fleet overview</h3>
    <p>Reuse the direct-IoT sample in [Build a Fleet Overview with AWS IoT Fleet Indexing](/blog/robot-fleet-overview).</p>
    <p className="learning-path__detail"><strong>Before:</strong> The stage 4 sample, AWS credentials, and working IoT certificates.</p>
    <p className="learning-path__detail"><strong>Outcome:</strong> Queryable connectivity and Device Shadow data across simulated robots.</p>
  </li>
</ol>

<aside className="advanced-path">
  <div className="advanced-path__label">Optional advanced path</div>
  <h3>Manage software with AWS IoT Greengrass</h3>
  <p>First learn [Greengrass concepts and components](/blog/greengrass-concepts-components), then attempt [automatic ROS 2-to-IoT conversion](/blog/automatic-ros2-greengrass-conversion).</p>
  <p><strong>Requires:</strong> a Docker-capable Greengrass server or EC2 instance, AWS CLI credentials, the Greengrass Development Kit, ECR repositories, and a reachable ROS 2 network.</p>
</aside>
